# Integrations - Notifications Module

Notification provider integration for MAVUNO-GREEN-GRID platform.

## Overview
Integrates with notification service providers.

## Features
- Email service integration
- SMS service integration
- Push notification service
- Chat service integration
- Webhook support

## Supported Providers
- SendGrid (Email)
- Twilio (SMS)
- Firebase (Push)
- Slack (Chat)
