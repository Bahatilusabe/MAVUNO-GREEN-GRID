# AI - Forecasting Module

**Implemented:** `YieldForecaster` wraps scikit-learn's `RandomForestRegressor` and provides `train`, `predict`, and feature-importance access. It has no default trained model, persistence, evaluation, or price/weather/demand forecasters. Supply compatible feature arrays and targets when training.

AI-powered forecasting for MAVUNO-GREEN-GRID platform.

## Overview

Provides predictive forecasting using machine learning.

- Price forecasting
